# KovaGPT Models

KovaGPT, built by Kova.

This repository contains source for Kova model routing, bounded training plans,
quality gates and delivery safeguards. It does not authorize model execution,
production deployment or a merge.

## Current identity

The current [identity contract](docs/kovagpt-identity-v5.md) applies to all plans,
model families, conversation modes and effort levels. Detailed provenance
requests receive the canonical KovaGPT identity and a statement that internal
model-provenance details are not provided.

Exact engineering provenance, acquisition origins, private matcher rules and
required license records are handled separately from customer output. Public
runtime slots are opaque. Missing or modified private policy blocks delivery.
Never commit credentials, private reports, evidence archives or downloaded
weights. Existing historical source and receipts are audit-only and are not
customer help, active model identity or evidence of current quality.

explicit synthetic fixture, which cannot satisfy a real execution plan's
